📖 Как выдать PIN сотруднику

Пошаговая инструкция для управляющего заведением

🔐 Что такое PIN и как он хранится

PIN — это 4-значный код для входа сотрудника в его кабинет (кухня / курьер / официант). PIN хранится в базе в зашифрованном виде (bcrypt-хеш) — никто, включая администраторов, не может увидеть оригинальный PIN.

⚠️ PIN показывается только один раз — при создании сотрудника или при сбросе. Сохраните его или сразу сообщите сотруднику.

➕ Шаг 1: Добавить нового сотрудника

1
Откройте Кабинет управляющего → выберите заведение
2
Перейдите на вкладку Повара, Курьеры или Официанты
3
Нажмите «+ Добавить»
4
Введите имя, телефон (для курьеров/официантов) и PIN из 4 цифр (или нажмите 🎲 для случайного)
5
Нажмите «Создать» → появится окно с PIN → сообщите PIN сотруднику
💡 Совет: используйте случайный PIN (кнопка 🎲) — это безопаснее чем «1234» или год рождения.

🔄 Шаг 2: Сбросить PIN (если забыли)

1
Откройте вкладку с нужным сотрудником
2
Нажмите кнопку «🔄 PIN» рядом с именем сотрудника
3
Подтвердите сброс → появится окно с новым PIN
4
Сообщите новый PIN сотруднику. Старый PIN перестаёт работать.
⚠️ После сброса старый PIN больше не работает. Если сотрудник не успел запомнить новый — сделайте сброс ещё раз.

📲 Шаг 3: Как сотрудник входит

1
Сотрудник открывает свою страницу: cook.html (повар), courier.html (курьер), waiter.html (официант)
2
Вводит код заведения (slug — виден в кабинете, кнопка «Копировать код»)
3
Вводит свой PIN (4 цифры)
4
Нажимает «Войти» → открывается рабочий кабинет
💡 Совет: скопируйте код заведения кнопкой «Копировать код» и отправьте сотруднику в мессенджер вместе с PIN.

📋 Шаг 4: Инструкция для сотрудника (скопируйте)

Вход для сотрудника:
1. Откройте сайт: ВАШ_САЙТ/cook.html
2. Код заведения: ВАШ_SLUG
3. PIN: ВАШ_PIN
4. Нажмите «Войти»

Заказы обновляются автоматически.

🗑 Удаление сотрудника

Нажмите «🗑» рядом с именем сотрудника → подтвердите удаление. Сотрудник потеряет доступ. Если нужно вернуть — создайте заново с новым PIN.
